02 / ChristEye technical documentation

From living metaphors to formal models.

Every meaningful system term needs a physical instance, an observable variable and a falsifiable test. These models specify what would have to be measured; they are not claims of a working prototype.

How to read the mathematics

Two complementary labeling schemes appear in the supplied documents. The Theory Set uses E established method, D derived proposal and H hypothesis. The physical design uses F reported finding in the cited preparation, X cross-study synthesis, H hypothesis and D engineering choice. Both prevent a design equation from being mistaken for experimental evidence.

Measured variables

Spike counts x, astrocytic readouts a, environment z, support q, feedback m, learned influence W, retained capability K, and output y require sensor, units and time window.

Not automatically measured

“Understanding,” “soul,” “heart,” “astroengram” or “wind” cannot be taken as directly observed biological quantities without an operational definition and discriminating experiment.

01. Coupled network dynamics

A reduced discrete-time state model couples recurrent electrical activity to encoded input, slower astrocytic state and environmental variables. This is a hypothesis model motivated by established population dynamics; it is not an identified parameterization of a real ChristEye cartridge.

MODEL H1 · NETWORK
xt+1 = f( Wxt + Bct + Gat + Dzt )

Here x is a binned neural signal vector, c the encoded task cue, a an astrocytic feature vector, z physical Soil, W the inferred recurrent influence, B/G/D coupling terms and f a nonlinear transfer function. Observed electrode interactions and anatomical synapses must remain separate graphs. Reference: Theory Set §3.1; Wilson–Cowan lineage of population modeling.

Astrocytic state and timescale

MODEL H2 · ASTROCYTES
τa ⊙ da/dt = −a + F(x, z, a)

The astrocytic term is slower-state modeling, not an assertion that astrocytes carry encoded task answers. A positive incremental prediction result supports information availability; a controlled perturbation is needed to argue causal contribution. Animal studies motivate this test, but do not validate human spinal cartridge memory storage.

02. Milk × Honey × eligibility

Eligibility eij records temporally local activity that could be modified. Honey m(t) is feedback contingent on an independently measured trial result; Milk q(t) is the separately measured adequacy of physiological support. Their proposed interaction gates change in the influence weight wij.

MODEL H3 · THREE-FACTOR CHANGE
τe deij/dt = −eij + Φ(xi, xj, Δt)
dwij/dt = η m(t) q(t) eij − λ (wij − wij0)

Interpretation: contingent feedback selects which eligible relation could change, while physiological adequacy limits permitted change. This is a proposed formalization inspired by reward-modulated STDP—not an experimentally validated biological law for the proposed preparation. The model cannot identify η, m and q from weight change alone; each has to be tracked separately.

Milk is a bounded support condition—not a reward

MODEL D1 · QUALIFICATION BAND
q(t) = ∏k exp{ −½ [ max(0, lk − zk, zk − uk) / sk ]² }

Each zk is a qualified measurement with bounds [lk, uk] and width sk. Within all valid bands q = 1; it declines outside. This continuous indicator is a statistical model. The independent limit controller must still enforce hard constraints; q below one is not permission to perform unsafe optimization.

Honey must carry outcome information

MODEL D2 · CONTINGENCY
I(φ; o) > 0 [contingent]   vs   I(φ; o) ≈ 0 [yoked]

φ is feedback and o is the protected outcome. A yoked control receives a recorded schedule divorced from its own outcome, ideally matched for total exposure. Mutual information should be estimated using an appropriate finite-sample method; perfect zero is an idealization, not an empirical expectation.

03. Roots, access and durable learning

The Theory Set distinguishes latent acquired capacity K from momentary ability to express it through access A. A nonresponse may reflect interface failure, context, support or actual loss of a learned relation; a single test cannot decide which.

MODEL D3 · EXPRESSION
Pobs = Pchance + (K − Pchance) A,   0 ≤ A ≤ 1

Access is an inferred latent factor; without independent observations K and A are not separately identifiable from one performance score. Rest or restored context can be diagnostic but does not by itself prove that a specific memory was intact.

MODEL D4 · RETENTION
RU(Δ) = [P(t₀+Δ) − Pchance] / [P(t₀) − Pchance]

The ratio is defined only if immediate trained performance is above chance. Values above 1 are possible if delayed performance improves; if it decreases below chance the ratio may be negative. Both must be reported rather than silently clamped. The physical design independently proposes absolute performance targets at 24 hours and seven days.

Generalization, flexibility and interference

MODEL D5 · TRANSFER
G = [Pnew − Pchance] / [Ptrain − Pchance]
MODEL D6 · PROTECTED SKILL LOSS
ΔRA = RUA(after B) − RUA(before B)

The Understanding vector is U = (R, G, F, C): retention, transfer, flexibility and calibration. These should not be condensed into an average that lets performance mask loss of calibration. Measure task-reversal cost F, held-out confidence calibration and old-task degradation separately. The “Tree” records validated relations among tasks, not merely a visually branching cell shape.

04. Testing the astroengram hypothesis

Animal results in hippocampus and amygdala support investigating experience-associated astrocytic ensembles. The proposed question here is narrower: does astrocytic observation provide task-specific information beyond neural activity and common causes in this exact preparation?

MODEL H4 · ADDED PREDICTIVE VALUE
ΔL = Lheld-out(neurons) − Lheld-out(neurons + astrocytes)

Positive ΔL means the larger feature set predicts better on locked held-out preparations. This is a predictive association. Compare environmental and batch confounders, identical model capacity and a held-out time split. Selective pathway tests with controls for generalized excitability are needed for causal interpretation. The term “astroengram” remains a research hypothesis, not an extracted molecule or transferable file.

05. Mesh and typed relations

The Mesh is a versioned set of four independent graph layers. A structural contact edge, statistical functional edge, controlled intervention edge and validated task relation must never be promoted into each other automatically. An electrode may measure a population and a functional graph edge may arise from common stimulation.

LayerEvidence / fieldsA false inference to avoid
StructuralImaging / contact / spatial coordinatesApparent proximity ≠ functional transfer
FunctionalConditional dependence, lag, context, uncertaintySynchrony ≠ synapse
InterventionManipulated route and measured outcomeUncontrolled disturbance ≠ causal route
TaskCue, context, response, retention, provenanceGood output ≠ complete mechanistic explanation

Branch relevance can be challenged with reversible software-side ablation of a signal route and an outcome change. A physical lesion is neither necessary nor equivalent for the first test. Redundant branches, common drive and contextual utility need separate interpretations.

06. Winds and electronic joining

A Wind is operationally a coded event sent to a named recipient: class, confidence, timing, source and codebook. A bridge encodes A’s delayed output as part of B’s input, and a binary switch controls that digital route.

MODEL D7 · JOINING
cBt = ctaskt + b(t) Enc(ŷAt−d, pAt−d),   b∈{0,1}

When a support module S is added, measure its contribution as a vector difference against matched nonadaptive support: κS = U(mesh+S) − U(mesh+fixed schedule). If retention improves but calibration worsens, both outcomes remain visible. This contribution is a hypothesis until evaluated.

07. Lotus decision and Heart veto

For the host/software instance of Lotus, decide among ACT, HOLD and UNRESOLVED using the uncertainty interval of benefit after costs and protected-skill risk. “Unresolved” is a useful state when evidence is inadequate. For the engineering instance of Heart, physical constraints are not weighted preferences.

MODEL D8 · LOTUS
J = E[ΔU] − αc − β|ΔRprotected|

ACT when J’s confidence lower bound exceeds zero; HOLD when the upper bound lies below zero; otherwise UNRESOLVED. This is one proposed coordinator policy, not evidence for a biological coordinating cell. The cost and ΔU terms must be normalized or declared componentwise before summing.

MODEL D9 · HARD VETO
permit(action) = ∏j 1[gj(state, action) ≤ 0]

A veto includes stale sensors, environmental excursions, forbidden stimulation profiles, inadequate rest, missing provenance or a protected retention violation. The digital learning policy cannot change safety thresholds to gain a better score.

08. Teaching and independent acquisition

MODEL D10 · SEPARATED TEACHING EFFECT
T = PB alone(taught) − max{ PB alone(yoked), PB alone(shuffled), PB alone(software teacher) }

The recipient must be evaluated alone with no cached teacher features, shared adaptive state or normalization. T > 0 across independent preparations would support a teaching benefit under declared controls, not direct transfer of the microscopic engram. Also report teaching efficiency S = 1 − Ntaught/Nself-trained.

09. Information, timing and energy

ESTABLISHED · RAW DATA RATE
Ḋ = 1,020 × 20,000 × (16/8) = 40.8 MB/s

That is approximately 146.9 GB/hour, or 3.53 TB/day for one continuously acquired raw 16-bit stream, before overhead. Plan an explicit recording duty cycle, event time stamps, artifact masks, compression rules and raw-retention windows.

ESTABLISHED · LOOP TIMING
tacquire + tdecode + tfeedback ≪ τeligibility
ESTABLISHED · ENERGY ACCOUNTING
ecorrect = Ewhole device/Ncorrect

Include host, recording hubs, storage, stimulation, environmental support and logistics in a system-wide power claim. A low-energy cell does not imply an efficient whole instrument. No energy advantage over software is established by these documents.

10. Further candidate relations from the Star corpus

The Theory Set’s second pass proposes additional formal ways to investigate Water overload, missingness, decision abstention, novelty, repair and branch utility. These are candidate model families, not universal physical equations. Each should specify a distinct input stream, comparison condition, threshold and counterexample.

FamilyOperational experimentFalsifying / separating observation
Water overloadResponse quality vs offered event rate and queuing delayPoor response explained by delayed delivery rather than loss of capacity
Access failureCompare original cue path with alternative valid routeFailure persists despite verified interface and support
Mesh relation utilityDisable candidate digital edge and retest UNo measurable loss after masking suggests redundancy
Attunement prisonExamine performance outside the over-practiced cue distributionSystem fails held-out counterexamples despite training gain
Novelty / error residualCompare residual mismatch on genuinely novel episodesResidual also appears from sensor noise or codebook drift
Repair without erasureRetest protected task A after a scoped correction to BOld task deteriorates beyond noninferiority margin
Formalization is not validation. Equation symbols and plausible mechanisms do not establish that a proposed organism or machine exhibits the modeled phenomenon. The validation plan makes each important H claim earn its own result.
