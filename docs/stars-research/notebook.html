Portability and future sync

Backups, import & API connection

No network services are configured or called. Back up locally after each session; your teammates will not see these records unless you transfer an exported file.

Export full backup

Exports tasks, trial statuses, runs, notes and stored file attachments encoded as JSON. Sensitive content will be present in cleartext in the backup.

Restore backup

Loads a previously exported workspace JSON. Replaces current task/runs/notes and adds its attachment files. A confirmation is required.

Future server adapter

assets/service-adapter.js declares a disabled transport contract. A future server should implement authenticated project-scoped endpoints, schema validation, content-addressed blob upload, server-side authorization, audit logs and conflict-aware revision checks. Merely adding a URL to this public site would expose data without that infrastructure.

GET  /api/v1/projects/{projectId}/workspace
PUT  /api/v1/projects/{projectId}/workspace   (If-Match version)
POST /api/v1/projects/{projectId}/attachments  (authenticated multipart)
GET  /api/v1/projects/{projectId}/attachments/{id}

No endpoint is enabled. No network call occurs.
Data safety: local browser storage may be cleared by the browser, privacy mode, storage quotas, or site-origin changes. It is not secure sharing, evidence immutability or backup. Export regularly. Do not store patient identifiers, secrets or restricted records in a public browser notebook.
